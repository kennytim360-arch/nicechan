How it works, in pictures

A pipeline is the list of steps that turns code into something people can use. Each step runs in its own sealed container, on your laptop and on the server, so the results match.

{{diagram1}}

Each run, Dagger saves the result of every step. If the code for a step has not changed, it reuses the saved result instead of doing the work again.
